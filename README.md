# Power BI Templates Library

A collection of reusable **Power BI** templates showcasing advanced dashboard design, dynamic DAX techniques, Power Query (M), custom themes, GeoJSON mapping, and interactive business analytics.

This repository is intended for:
- Data Analysts
- Business Intelligence Developers
- Companies
- Organizations
- Reusable Dashboard Templates
- Power BI Learners


## Features Demonstrated
* Interactive dashboards
* Dynamic KPI switching
* Dynamic Top/Bottom N Ranking
* Field Parameters
* Advanced DAX Measures
* Time Intelligence
* Conditional Formatting
* Custom Power BI Themes
* GeoJSON Mapping
* Responsive report layout
* Reusable Power BI Templates (.PBIT)

## Each template may include:

Each template in this repository is provided as a complete package to help you understand, customize, and reuse the solution.

- Power BI Report (`.pbix`)
- Power BI Template (`.pbit`)
- Sample Dataset (`.csv`)
- DAX Documentation
- Data Model Documentation
- Dashboard & Model View Screenshots
- GeoJSON Map Files (when applicable)
- Python Scripts (if used for data generation or preprocessing)
- Project README with setup instructions
